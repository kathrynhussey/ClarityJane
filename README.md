# ClarityJane
## Repository description
Website for Clarity Jane Coaching with Kathryn Hussey, helping people move from calamity and uncertainty to clarity, confidence and meaningful change.
## Before publishing

1. In `index.html`, replace both instances of `YOUR-EMAIL@EXAMPLE.COM` with Kathryn's email.
2. Replace the photo placeholder with Kathryn's professional photograph when available.
3. Personalise Kathryn's biography, qualifications and coaching approach.
4. Replace the booking button with a Calendly, Microsoft Bookings or other booking link if desired.
5. Add a privacy notice before collecting visitor information.

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css` and `script.js` to the repository root.
2. Open repository **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then **Save**.
5. GitHub will display the free Pages address once deployed.

Do not add a `CNAME` file until the `clarityjane.com` domain has been purchased and configured.
